# M5 ĐO ĐẠC — free measuring tools for AutoCAD

**[Download the latest version](https://github.com/arcthanhbinhtran-ai/m5-do-dac/releases/latest)** · **[Website](https://arcthanhbinhtran-ai.github.io/m5studio/chi-tiet.html?id=m5-do-dac&lang=en)** · by [M5 STUDIO](https://arcthanhbinhtran-ai.github.io/m5studio/?lang=en)

Select lines or areas and instantly get the total length and total area, with a result table per object and per layer. Free, for AutoCAD 2015 – 2027.

- Total length of polylines, lines, arcs, splines, ellipses
- Area of hatches and closed polylines (m², ha), find and subtract overlaps
- Red marks on gaps of open polylines, close them in one click
- Convert splines / ellipses to polylines, smooth polylines
- Divide a path evenly: points, split pieces or blocks (rotate, mirror)
- Blocks: replace, rename, change base point, toggle Annotative — no Block Editor needed
- Built-in update check (updates without restarting AutoCAD)

> **Interface language:** Vietnamese for now. An English interface is planned.

## Install

1. Download `M5DODAC_vX.Y.zip` from [Releases](https://github.com/arcthanhbinhtran-ai/m5-do-dac/releases/latest) and **unzip** it.
2. Close AutoCAD, double-click **`M5DODAC_vX.Y_CaiDat.exe`** in the unzipped folder.
3. If Windows shows “Windows protected your PC”, click **More info → Run anyway** (the installer is not code-signed yet).
4. Open AutoCAD: a new **M5 ĐO ĐẠC** ribbon tab appears.

This repository only hosts the release files.
